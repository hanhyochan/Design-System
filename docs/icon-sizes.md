# SVG 원본과 견본 크기

Foundation에 포함된 SVG 394개를 파일명 순으로 정리했습니다. 원본 속성은 SVG 파일에서, 견본 너비는 Storybook 아이콘 갤러리에서 가져왔습니다. [SVG 원본](../packages/foundation/src/icons/) · [갤러리 표시 규칙](../apps/storybook/stories/foundation/Icons.stories.tsx) · [파일별 견본 너비](../apps/storybook/stories/foundation/icon-gallery-groups.ts)

- **원본 너비 × 높이**는 루트 `<svg>`의 `width`와 `height` 값입니다. `-`는 해당 속성이 생략됐다는 뜻입니다.
- **viewBox 너비 × 높이**는 SVG 내부 좌표계의 크기입니다. 소수점은 원본의 정밀도를 유지했습니다.
- **견본 너비**는 갤러리에서 이미지에 지정한 CSS 너비입니다. 기본값은 24px이고 견본 버튼은 24×24px입니다. 이미지는 비율을 유지하며 높이는 최대 24px입니다.
- 실제 Button·Tab·Select 등에서 아이콘을 끼우면 각 컴포넌트가 정한 너비를 사용합니다. [컴포넌트별 규격](design-rules.md)
