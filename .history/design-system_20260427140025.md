# Design System Guide

이 문서는 새 프로젝트에서 AI에게 단독으로 전달해도 현재 디자인 시스템의 전역 reset, 파운데이션 토큰, 컴포넌트 스펙을 재현할 수 있도록 만든 기준서다.

핵심 목표는 다음과 같다.

- `global.css` 또는 전역 스타일 파일에 reset 코드와 파운데이션 토큰을 자동 생성할 수 있어야 한다.
- 색상, 폰트, spacing, radius, border, shadow 값을 새로 만들지 않고 현재 디자인 시스템 토큰을 그대로 사용해야 한다.
- 컴포넌트는 현재 디자인 시스템의 개별 복붙 class를 그대로 복제하는 것이 아니라, 동일한 시각 스펙을 가진 재사용 가능한 컴포넌트로 구현해야 한다.
- 버튼, 카드, 폼, 테이블, 탭, 입력 요소, 선택 컨트롤, 칩, 배지, 토글, 체크박스, 라디오를 모두 이 문서 기준으로 만들 수 있어야 한다.

## 1. AI 적용 지시문

새 프로젝트를 생성하거나 기존 프로젝트에 적용할 때 AI에게 아래 지시를 그대로 전달한다.

```text
design-system.md의 규칙을 반드시 따르고, 아래 보일러 템플릿 구조를 유지해서 프로젝트를 생성해.
새로운 스타일을 임의로 만들지 말고 기존 토큰/컴포넌트를 재사용해.
전역 CSS에는 이 문서의 reset 코드와 foundation token 전체를 포함해.
컴포넌트는 현재 디자인 시스템의 시각 스펙을 유지하되, 복붙용 개별 클래스가 아니라 재사용 가능한 구조로 구현해.
컴포넌트 구현 시 height, padding, font-size, font-weight, line-height, radius, border, color, state 규칙은 이 문서의 spec을 따라.
```

## 3. 전역 CSS reset

아래 reset 코드는 새 프로젝트의 전역 CSS에 그대로 포함한다.

```css*,
*::before,
*::after {
  box-sizing: border-box;
}

html {
  font-size: var(--font-size-16);
  -webkit-text-size-adjust: 100%;
}

body {
  min-height: 100vh;
  margin: 0;
  color: var(--color-label-strong);
  font-family:
    "Noto Sans KR", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;
  line-height: var(--line-height-140);
}

button,
input,
select,
textarea {
  margin: 0;
  color: inherit;
  font: inherit;
}

button {
  border: 0;
  background: none;
  cursor: pointer;
}

a {
  color: inherit;
  text-decoration: none;
}

ul,
ol {
  margin: 0;
  padding: 0;
  list-style: none;
}

img,
picture,
video,
canvas,
svg {
  display: block;
  max-width: 100%;
}

table {
  border-collapse: collapse;
  border-spacing: 0;
}

fieldset {
  min-width: 0;
  margin: 0;
  padding: 0;
  border: 0;
}

legend {
  padding: 0;
}
```

### 3.1 Reset 설명

- `box-sizing: border-box`: 모든 요소와 pseudo element의 크기 계산 기준을 통일한다.
- `html font-size`: 기본 폰트 크기를 `--font-size-16`에 연결한다.
- `-webkit-text-size-adjust: 100%`: 모바일 브라우저 자동 텍스트 확대를 방지한다.
- `body min-height: 100vh`: 기본 화면 높이를 보장한다.
- `body margin: 0`: 브라우저 기본 여백을 제거한다.
- `body color`: 기본 텍스트 색상은 `--color-label-strong`이다.
- `body font-family`: `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif` 순서를 사용한다.
- `body line-height`: 기본 행간은 `--line-height-140`이다.
- `button, input, select, textarea`: form control은 margin 제거, color/font 상속을 적용한다.
- `button`: 기본 border/background 제거, pointer cursor 적용.
- `a`: 색상 상속, underline 제거. 본문 링크 underline이 필요하면 해당 영역에서 별도 정의한다.
- `ul, ol`: 기본 margin, padding, list marker 제거.
- `img, picture, video, canvas, svg`: block 요소로 만들고 부모 너비를 넘지 않게 한다.
- `table`: `border-collapse: collapse`, `border-spacing: 0`으로 테이블 기본 틈을 제거한다.
- `fieldset`, `legend`: 브라우저 기본 form grouping 스타일을 제거한다.

- `status`: positive, cautionary, negative 상태 token.
- `shadow`: shadow preset에서 사용하는 alpha color token.
- `opacity`: 투명도 scale token.
- `brand`: 브랜드별 custom palette.

색상 사용 원칙:

- UI 구현에서는 semantic token을 우선 사용한다.
- atomic palette는 새로운 semantic token 설계 없이 남발하지 않는다.
- 상태 의미가 있는 색은 status token을 사용한다.
- primary action은 현재 컴포넌트 스펙과 동일하게 blue 계열을 사용한다.
- hardcoded hex, rgb, hsl 값을 새로 쓰지 않는다.

## 5. Reusable Component 구현 규칙

현재 디자인 시스템의 component CSS는 확인과 복붙을 위해 조합별 class가 개별로 존재한다. 새 프로젝트에서는 아래 spec을 기준으로 재사용 가능한 컴포넌트를 만든다.

권장 API 예시:

```tsx
<Button variant="filled" size="medium" shape="square">저장</Button>
<Button variant="outline" size="small" icon="alarm">알림</Button>
<TextInput variant="outline" size="medium" state="error" />
<Tab variant="grayLineOutline" size="medium" active />
```

구현 원칙:

- `variant`, `size`, `shape`, `state`, `icon`, `disabled` 같은 의미 prop으로 분리한다.
- 현재 디자인 시스템의 class name은 mapping 참고용으로만 사용한다.
- 모든 최종 CSS 값은 아래 spec을 따른다.
- 컴포넌트 내부 스펙을 화면별 CSS에서 덮어쓰지 않는다.

## 6. Component Specs

### 6.1 Button

대상: primary button, icon button, text button.

Base:

- `display: inline-flex`
- `align-items: center`
- `justify-content: center`
- `font-weight: 500`
- `white-space: nowrap`
- `appearance: none`
- `cursor: pointer`

Primary button size:

| Size | Min height | Padding X | Font size | Line height |
| --- | ---: | ---: | ---: | ---: |
| small | 32px | 16px | 12px | 16px |
| medium | 40px | 24px | 14px | 20px |
| large | 48px | 24px | 16px | 20px |

Primary variant:

| Variant | Background | Text | Border | Hover |
| --- | --- | --- | --- | --- |
| filled | `--color-blue-50` | `--color-common-100` | 0 | `--color-blue-40` |
| outline | white/transparent | primary or label color | `--border-1` solid line token | current outline hover pattern |
| disabled | `--color-interaction-disable` | `--color-label-disable` | variant 기준 | none |

Shape:

| Shape | Radius |
| --- | --- |
| default/square | `--radius-0` |
| rounded | `--radius-8` |
| full rounded | `--radius-full` |

Shadow:

- small shadow: `--shadow-2`
- medium shadow: `--shadow-3`
- large shadow: `--shadow-3` 또는 현재 컴포넌트 preset
- hover 시 shadow는 제거하는 패턴을 따른다.

Icon button:

| Size | Control size | Icon size | 용도 |
| --- | ---: | ---: | --- |
| small | 32px | 16px | 작은 도구 버튼 |
| medium | 40px | 20px | 일반 도구 버튼 |
| large | 48px | 24px | 강조 도구 버튼 |
| xlarge | 52px | 24px | 큰 touch target |

Text button:

| Size | Font size | Line height | Weight |
| --- | ---: | ---: | ---: |
| small | 12px | 16px | 500 |
| medium | 14px | 20px | 500 |

Button rules:

- 한 action group에 primary filled button은 하나만 둔다.
- 보조 액션은 outline 또는 text button을 사용한다.
- disabled 상태는 실제 `disabled` 속성과 함께 적용한다.
- 아이콘은 의미가 있을 때만 사용한다.

- `display: inline-flex`
- `align-items: center`

- `white-space: nowrap`
- `cursor: pointer`

Size:

| Size | Min height | Padding X | Font size | Line height |
| --- | ---: | ---: | ---: | ---: |
| small | 32px | 12px | 14px | 20px |
| medium | 40px | 16px | 15px | 20px |
| large | 48px | 24px | 16px | 20px |

Variant:

- filled: normal `--color-fill-normal`, active `--color-blue-50` + white text.
- outline: line border 기반.
- gray line outline: neutral line border 기반.
- icon: text 앞 icon 포함.
- rounded: `--radius-8`.
- full rounded: `--radius-full`.

- 같은 tab group 안에서 size와 shape를 섞지 않는다.

Size:

| Size | Min height | Padding X | Font size | Line height |
| --- | ---: | ---: | ---: | ---: |
| small | 32px | 12px | 14px | 20px |
| medium | 40px | 16px | 15px | 20px |
| large | 48px | 24px | 16px | 24px |

Variant/state:

- filled: `--color-blue-50`, white text, active `--color-blue-40`.
- outline: white background, strong border/text, active inverted.
- gray line outline: neutral line border, white background, active black background.
- disabled: disabled background/text and actual disabled when interactive.

Badge rules:

- Badge는 클릭 요소가 아니다.
- 클릭 가능한 선택 UI는 chip을 사용한다.

## 7. 공통 패턴

### 7.1 Card

현재 별도 card component CSS는 없다. 새 프로젝트에서는 아래 스펙으로 reusable card를 만든다.

```css
.card {
  padding: var(--spacing-padding-vertical-24) var(--spacing-padding-horizontal-24);
  border: var(--border-1) solid var(--color-line-normal-neutral);
  border-radius: var(--radius-8);
  background: var(--color-background-elevated-normal);
  box-shadow: var(--shadow-1);
}
```

Card rules:

- 내부 padding은 16, 24, 32 중 선택한다.
- 카드 안에 카드를 중첩하지 않는다.
- clickable card는 focus style을 제공한다.

### 7.2 Form

```css
.form-stack {
  display: grid;
  gap: var(--spacing-gap-vertical-16);
}

.field {
  display: grid;
  gap: var(--spacing-gap-vertical-8);
}

.field-label {
  color: var(--color-label-normal);
  font-size: var(--font-size-14);
  font-weight: var(--font-weight-500);
  line-height: var(--line-height-20);
}
```

Form rules:

- label을 placeholder로 대체하지 않는다.
- 같은 form 안에서 control size를 섞지 않는다.
- 기본 size는 medium이다.
- error visual과 error message를 함께 제공한다.

### 7.3 Table

```css
.table-wrap {
  overflow-x: auto;
  border: var(--border-1) solid var(--color-line-normal-neutral);
  border-radius: var(--radius-8);
  background: var(--color-background-elevated-normal);
}

.data-table {
  width: 100%;
  min-width: 640px;
}

.data-table th,
.data-table td {
  padding: var(--spacing-padding-vertical-12) var(--spacing-padding-horizontal-16);
  border-bottom: var(--border-1) solid var(--color-line-normal-alternative);
  color: var(--color-label-normal);
  font-size: var(--font-size-14);
  line-height: var(--line-height-20);
  text-align: left;
  vertical-align: middle;
}

.data-table th {
  background: var(--color-background-normal-alternative);
  color: var(--color-label-neutral);
  font-weight: var(--font-weight-500);
}
```

Table rules:

- 상태 표시는 badge를 사용한다.
- 행 액션은 text button 또는 icon button을 사용한다.
- 좁은 화면에서는 horizontal scroll wrapper를 사용한다.
- table 안에 card를 중첩하지 않는다.

## 8. 금지사항

- hardcoded hex, rgb, hsl color를 새로 쓰지 않는다.
- hardcoded spacing 값을 새로 쓰지 않는다.
- token에 없는 font size를 쓰지 않는다.
- 13px, 115px를 다시 만들지 않는다.
- Label_2, Display_4, Title_3, Body_3를 만들지 않는다.
- 컴포넌트 스펙의 padding, height, radius, color를 화면별 CSS에서 덮어쓰지 않는다.
- disabled처럼 보이는 스타일만 만들고 실제 disabled 처리를 누락하지 않는다.
- button 역할을 div로 만들지 않는다.
- badge에 클릭 동작을 넣지 않는다.
- primary filled button을 같은 action group 안에 여러 개 두지 않는다.
- shadow를 장식 목적으로 남발하지 않는다.
- `!important`를 쓰지 않는다.

## 9. 자동 생성 체크리스트

- 전역 CSS에 color, spacing, decorate, typography token이 모두 들어갔는가?
- reset 코드가 이 문서의 reset 기준과 같은가?
- `body` font family, color, line height가 유지됐는가?
- 컴포넌트는 재사용 가능한 API로 설계됐는가?
- 각 component size별 height, padding, font size, line height가 이 문서와 같은가?
- variant와 state 색상이 이 문서의 semantic token을 사용하는가?
- 13px, 115px, hardcoded hex, 임의 px 값, `!important`가 없는가?
- form control에 label, disabled, readonly, aria 상태가 올바르게 연결됐는가?
